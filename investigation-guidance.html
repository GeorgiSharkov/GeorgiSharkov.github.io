        HOW TO USE IT

        Built for analyst flow, not ATT&CK memorisation

        Search the alert family first

        Start with the alert wording you already have from the SIEM, EDR, email gateway, or case queue. The page is designed to meet analysts where the alert begins, then map that alert to ATT&CK context.

        Use ATT&CK as context, not as a shortcut

        ATT&CK helps anchor the alert pattern, but the page still forces evidence review, host and user context, and practical remediation.

        Grow the matrix over time

        The current page is a working reference for common cases such as PowerShell, phishing links, suspicious downloads, credential dumping, identity abuse, persistence, service creation, registry changes, removable media, lateral movement, and tool transfer. It can expand as your alert coverage grows.
