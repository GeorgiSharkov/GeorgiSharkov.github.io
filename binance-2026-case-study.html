WHAT HAPPENED / [1]

Access reached the signer

Binance reports developer compromise, a pivot through internal AI tooling, stolen deployment credentials, and unauthorized wallet signing. Its findings remain preliminary.

SCALE / [2–3]

The biggest recent case

Chainalysis estimates about $6.4 billion stolen and calls this the largest crypto theft recorded. The FBI attributes the attack to North Korea’s TraderTraitor activity.

WHY SOC TEAMS CARE

Authentication is one checkpoint

A trusted user, familiar developer tool, or successfully signed request still needs an explanation. Correlate the identity, device, deployment, requested action, and business approval before treating access as legitimate.

03 / THE AUTHORIZATION PROBLEM

A withdrawal pause is only one control.

EIP-7702 is a legitimate Ethereum capability. Its specification describes persistent code delegation for externally owned accounts, including a way to clear that delegation. [4]

PROTOCOL CONTEXT / [4]

Delegation changes what an account can execute.

An authorization points an account at contract code. The delegation survives the transaction; it is not an ordinary one-time token transfer or merely an ERC-20 allowance.

For defenders, inspect the authorized chain, account, target and nonce. Verify the resulting state and delegated code, not just the transaction’s success status.

INCIDENT LESSON / [1]

Local shutdown does not reset remote authority.

Binance says existing on-chain authorizations outlived its withdrawal suspension. Keep application containment and authority revocation as separate response workstreams.

Analyst inference: a quiet application dashboard cannot establish that delegated execution has stopped.

05 / SOC HUNT PACK

Hunt the path into authority.

Original queries for analogous environments. These are investigation starting points, not Binance telemetry or production-tested signatures. Confirm data coverage and tune legitimate package maintenance and deployments.

Defender / pyenv file changes
DeviceFileEvents
| where Timestamp > ago(30d)
| where FolderPath contains "/Cellar/pyenv/"
| where FolderPath contains "/libexec"
| where FileName in ("pyenv", "pyenv_")
    or PreviousFileName in ("pyenv", "pyenv_")
| project Timestamp, DeviceName, ActionType, FolderPath,
    FileName, PreviousFileName, SHA1, InitiatingProcessFileName,
    InitiatingProcessCommandLine, InitiatingProcessAccountName
| order by Timestamp desc

Requires supported macOS file telemetry. Review changes against approved maintenance and validate your collection coverage.

Correlate the layers

Join endpoint activity to identity sessions, deployment audit, signing decisions and transaction hashes using defensible timestamps and identifiers. Review coverage gaps. No results in one log source do not clear the other layers.

06 / RESPONSE PLAYBOOK

Contain authority, then restore trust.

Recommended actions for a comparable intrusion. Cryptocurrency operations and revocation need the wallet, infrastructure and incident-response owners working together.

01 / PRESERVE

Keep the evidence.

  1. Isolate affected devices while retaining volatile evidence where feasible.
  2. Preserve tool, identity, deployment and signing audit records.
  3. Record chains, wallets, transaction hashes, block times and approval context.
02 / REVOKE

Close both paths.

  1. Revoke exposed sessions, tokens and deployment access.
  2. Restrict signing capability through the approved emergency process.
  3. Inventory and revoke unauthorized on-chain permissions; verify the resulting state.
03 / RECOVER

Rebuild from trust.

  1. Replace affected workloads and endpoints from trusted sources.
  2. Rotate exposed secrets and review who can issue signing requests.
  3. Coordinate asset tracing and freeze requests with relevant issuers and investigators.
04 / PROVE

Test the recovery.

  1. Check restored services against deployment and signing policy.
  2. Validate that old identities and unauthorized delegation paths cannot act.
  3. Record exceptions, outstanding evidence gaps and the owner accepting residual risk.

ASSET RESPONSE / CHAINALYSIS FINDINGS [2]

Frozen is a response state, not a recovery total.

Chainalysis reported about $2.8 billion frozen as of 3 November. It observed rapid stablecoin conversion and transaction patterns suggesting automation. A freeze restricts movement; it does not mean the assets have already returned to the victim. Track recovered, frozen and still-moving amounts separately.
